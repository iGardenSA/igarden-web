#### 18. نَبني · نُوطّن · نُطوّر
- **EN:** We Build · We Localize · We Develop
- **Tier:** 0 · 1 · 2 · 3 (مرقّى لجميع الطبقات — قرار CEO 17 مايو 2026)
- **Status:** ✅ Approved — Tier 0 Public (**Secondary** تحت Primary "ازرع بذكاء")

**🔴 القاعدة الصارمة (الهرم الشعاراتي):**
- **Primary** = "ازرع بذكاء"
- **Secondary** = "نَبني · نُوطّن · نُطوّر"
- **الشعاران لا يُجمعان في سياق لغوي واحد أبداً** — لا في سطر واحد، لا في فقرة، لا بأي فاصل (—، .، ·، أو أي حرف عطف)

**📐 قواعد الاستخدام حسب السياق:**

**أ. العناصر المرئية (Hero · Footer · أي UI):**
الشعاران كعنصري HTML منفصلين (سطران مختلفان، markup مختلف)، مع Primary أبرز بصرياً.
```tsx
<h1 className="text-5xl">ازرع بذكاء</h1>
<p className="text-sm text-lime/70">نَبني · نُوطّن · نُطوّر</p>
```

**ب. النصوص غير المرئية (meta · OpenGraph · Schema/JSON-LD · alt text):**
يُذكر شعار واحد فقط — **"ازرع بذكاء"** (Primary). لا يُذكر "نَبني..." في هذه السياقات.
```tsx
// صحيح:
description: "شركة سعودية لتطوير المزارع. ازرع بذكاء."
// خاطئ:
description: "...ازرع بذكاء — نَبني · نُوطّن · نُطوّر."
description: "...ازرع بذكاء. نَبني · نُوطّن · نُطوّر."
description: "...نَبني · نُوطّن · نُطوّر." // بدون Primary
```

**ج. الاستثناء السياقي:**
في about/methodology و products: "نَبني..." يصلح وحده كـ heading أو eyebrow لأنه موضوع الصفحة، لا شعار مرافق.

**الإملاء المعتمد:** `نَبني` (مع فتحة) — `نبني` (بلا فتحة) **غير معتمد**

**Forbidden:**
- ❌ جمع الشعارين في سياق لغوي واحد
- ❌ "نَبني..." كـ Primary أو بحجم أكبر من "ازرع بذكاء"
- ❌ "نَبني..." في meta/schema/alt
- ❌ الإملاء `نبني` بلا فتحة

- **Brand Bible:** 2.4 + 9.1 + Decision DB (17 مايو 2026)

- **Tier:** 2-A · 2-B

#### 27. Target Margin · هامش مستهدف
- **Tier:** 2-A · 2-B
- **إلزامي:** تبرير اقتصادي مصاحب
- **Forbidden:** "هامش مضمون"، "هامش عالي" بلا تبرير

#### 28. Revenue Mix · مزيج الإيرادات
- **Tier:** 2-A · 2-B
- **متميّز عن:** نسب الملكية بين المؤسسين (تلك محظورة في كل الـ Tiers)

#### 29. TAM / SAM / SOM
- **Tier:** 2-A · 2-B
- **إلزامي:** كل رقم يحتاج مصدر (Mordor Intelligence، USDA، MEWA، إلخ)

- **Forbidden:** أرقام بلا مصدر

- **Tier:** 2-A · 2-B
- **Context:** CAC، LTV، Payback Period، Gross Margin per Unit

#### 31. Runway · فترة التشغيل المتاحة

- **Context:** عدد الأشهر حسب الحرق الشهري

#### 32. Funding Ask · التمويل المطلوب

## الفئة 10: Disclaimers إلزامية — Tier 2-A

#### 39. Subject to Revision Disclaimer
- **AR:** `قابل للمراجعة` / `خط الأساس · قابل للمراجعة`
- **EN:** `Subject to revision`
- **الإلزام:** أي projection مالي (Year 1+) يجب أن يحمل هذا

#### 40. Methodology Note
- **AR:** "محسوب على أساس [pipeline funnel / market sizing / unit economics]"
- **الإلزام:** أي رقم يتجاوز baseline يحتاج إشارة لـ methodology

#### 41. External Source Citation
- **AR:** "(المصدر: [الجهة]، [السنة])"
- **الإلزام:** أي رقم للسوق الخارجي (TAM/SAM) يحتاج مصدر
- **مثال:** `Saudi protected agriculture market: USD 2.4B by 2030 (Mordor Intelligence, 2025)`

## خريطة القرار السريعة (Tier 2-A)

عند الكتابة في pitch deck، لكل رقم:
1. **هل الرقم محسوب أم اعتباطي?** — اعتباطي → أصلحه
2. **هل هو baseline أم projection?** — projection → disclaimer إلزامي
3. **هل يكشف عميلاً أو مؤسساً بصفة شخصية?** — نعم → محظور
4. **هل يدّعي شراكة غير موجودة?** — نعم → محظور
5. **هل للرقم مصدر خارجي?** — نعم → أضف citation
